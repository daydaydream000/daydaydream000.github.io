在这里，我会记录自己的所思所学——可能是踩过的技术坑、读过的书、随手写下的想法，也可能只是一场白日梦。

## 这个博客是怎么搭起来的？

完全运行在 GitHub 上，零成本、零服务器：文章写在 GitHub Issues 里，由 GitHub Actions 自动构建，托管在 GitHub Pages。写完一篇 Issue、打上标签，几秒后就会自动出现在博客上。

## 你能看到什么

- 📝 随笔与思考
- 🛠️ 技术笔记
- 📚 读书与生活记录
