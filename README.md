# DayDayDream

> 醒着做梦，落笔成诗——记所思，存所学。

基于 [Gmeek](https://github.com/Meekdai/Gmeek) 搭建的零成本、无服务器博客：文章写在 GitHub Issues 里，由 GitHub Actions 自动生成静态页面，通过 GitHub Pages 的「从分支 /docs 文件夹发布」模式托管。

- 博客地址：https://daydaydream000.github.io/
- 写文章：在仓库开一个 Issue，打上至少一个标签即可自动发布
- 关于页：开 Issue 并打 `about` 标签（已在 config.json 的 singlePage 中配置）
