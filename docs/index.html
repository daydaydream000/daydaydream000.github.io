ARPG 学习日志 Day 13：掉落物、拾取动画与那 0.5 秒

2026-10-29Unity10 分钟

把一个「地上的东西」拆成四件：一份 ItemSo 数据、一个只有 SpriteRenderer 的子物体、一个 IsTrigger 的圆形碰撞、一个 Loot 脚本。玩家走进触发区 → 播 LootPickup（0.333 秒）→ 广播 OnItemLooted → 0.5 秒后销毁。记这一天的坑：OnValidate 只在编辑器跑、prefab 的空数据会造出「看不见也捡不到」的物体、Destroy 的 0.5 秒受 timeScale 影响、触发窗口里可以重复发放，以及最要紧的一条——敌人死了不掉东西，这套系统目前没有入口。
