ARPG 模块专文（六）：关卡与相机——七层瓦片与两条相机链

2026-11-05Unity5 分钟

关卡模块不参与任何战斗，它只做两件事：挡住不该走的地方、决定谁画在前面。七层 Tilemap 里只有 3 层有碰撞体且没有 CompositeCollider2D；相机有两条链，Cinemachine 跟玩家、ShopKeeperCamera 只把画面拍进 256×256 的 RenderTexture；「钻山洞」靠关碰撞体 + 改 sortingOrder 15/10 伪造出高低差。最后把 Tag / Layer / sortingOrder 三个「静默失效」的机制摆在一起对照。

ARPG 模块专文（五）：表现层——六张 Canvas 与三个暂停者

2026-11-05Unity5 分钟

表现层是 6 张 Screen Space - Overlay 的 Canvas、4 个 CanvasGroup、3 个「暂停者」。它们之间没有统一的面板管理器，属性面板 / 技能树 / 商店各自把 Time.timeScale 按到 0，各记一个 bool，谁也不看谁。同时记下三个结构性问题：ExpManager 挂在 ExpCanvas 上（关 HUD 就断链）、ShopInfo 把屏幕坐标当画布坐标用、面板互斥没有引用计数；另有两处配置遗留：ExpCanvas 参考高度 108、InfoPopup 初始 alpha 为 1。

ARPG 模块专文（四）：物品与商店——从地上捡到换成钱

2026-11-05Unity6 分钟

物品模块是全场最长的一条链：Loot 触发器发 OnItemLooted → InventoryManager 分流金币/堆叠/空格/溢出 → InventorySlot 左键使用或卖出、右键丢弃 → UseItem 改 StatsManger；商店则是 ShopKeeper 触发圈 + K 开店 + OnShopStateChanged 通知背包「现在开着哪家店」。同时指出三处断链（击杀不掉物品、卖出不校验导致物品蒸发、背包没有开关）和两处实现 bug（空格能塞超 stackSize、ShopInfo 用 SO 名而不是 itemName）。
