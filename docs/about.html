关于本站

本站是一个纯静态博客：没有数据库，没有服务器，也没有套用现成的博客模板。

  • 内容：Markdown，放在仓库的 posts/ 与 pages/ 目录；
  • 生成：仓库自带的 build.py，只用 Python 标准库，零第三方依赖；
  • 托管：GitHub Pages，发布源是 main 分支的 /docs 目录。
