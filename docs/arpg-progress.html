这是「ARPG 学习日志」系列的进度总览，随每篇日志一起更新。截至 Day 15（2026-11-02），工程处于「能走、能打、能升级、能捡、能装、能买卖，但世界里还没有东西可捡、店也关不掉」的状态。

一句话概括：从键盘到伤害、到成长、到物品、到交易的五条链都通了；断的是「世界里为什么会有这些东西」和「那间店为什么关不掉」。

现在能玩到什么

已经通了还断着
WASD 移动、四态动画、走进山体时沉到山后玩家死亡：PlayerHealth 归零只是 SetActive(false)，没有死亡/重生流程
相机跟随 + 地图边界约束敌人刷新：全场仍只有一只 Enemy_Torch，打死后不重来
挥剑命中：扣血、击退、眩晕技能树：24 个节点里 15 个是同一份「Max Health Boost」，8 个落进 default
弓箭：八向瞄准、动画事件出箭、插墙、命中扣血掉落表：敌人只给经验，地上永远不会自然出现物品
击杀 → 经验 → 升级 → 能力点 → 花点解锁技能商店关不掉：OnShopStateChanged 只在 Start 广播一次 true，于是背包左键被永久征用成「卖」
Esc 属性面板、K 技能树面板（都会暂停）卖出不校验：商店不收的东西也会被扣掉一个（物品蒸发）
物品：拾取动画、堆叠、左键使用、右键丢弃、溢出回到地上背包 / 商店面板没有开关：一个 sortingOrder −1 常驻，一个 α 1 常驻
买卖：TryBuyItem 查钱查空间、扣钱入包；卖价借用商品价存档：等级、技能、背包、金币、商品状态全部在内存里，重开归零
金币：isGold 分流进 gold 计数，不占背包格面板互斥：两个暂停面板共享 Time.timeScale，关任一个时间就恢复

六条数据流

移动

Input → PlayerMovement.FixedUpdate → rb.velocity = dir × StatsManger.speed → Animator（Idle/Run/Jump/Fall）

近战

Input(Slash) → Player_Combat.Attack() → 动画事件 → DealDamage() → OverlapCircleAll(enemyLayer) → Enemy_Health.ChangeHealth(-1) → Enemy_Knockback.Knockback(...)

远程

Input(Shoot) → Player_Bow 定身 + SetBool → Shoot 状态 → 动画事件 Shoot() → Instantiate(Arrow) → OnCollisionEnter2D → 敌人扣血 / 障碍插墙 → 2 s 销毁

成长

Enemy_Health ≤ 0 → OnMonsterDefeated(10) → ExpManager → OnLevelUp(1) → SkillTreeManager 发点 → SkillSlot.TryUpgradeSkill → OnAbilityPointSpent → 扣点 + SkillManager 改属性

物品

Loot.OnItemLooted(itemSo, n) → InventoryManager.AddItem（金币 / 堆叠 / 空槽 / 溢出）→ InventorySlot.OnPointerClick → UseItem.ApplyItemEffects → StatsManger.Update*

交易

ShopSlot 按钮 → ShopManager.TryBuyItem（钱够 + 有空间）→ gold -= price → InventoryManager.AddItem(itemSo, 1)　｜　背包左键 → activeShop.SellItem(itemSo) → 在 shopSlots 找同款 → gold += slot.price

问题清单

P0：挡住「可玩」

#问题位置后果
1没有掉落表无敌人只给经验，地上永远不会自然出现物品
2商店关不掉ShopManager.StartOnShopStateChanged 只发过一次 true、没有 false；activeShop 永不为 null → 背包左键永远是「卖」，所有「使用道具」失效
3卖出不校验ShopManager.SellItem没有返回值；商店不收的物品也会被扣掉一个 → 物品蒸发
4背包 / 商店没有开关InventoryCanvas / ShopCanvas一个常驻 −1 层、一个常驻 α 1 并挡住鼠标
5静态事件没有 ?.InvokeEnemy_Health.ChangeHealth没订阅者时抛异常 → Destroy 不执行 → 敌人不死
6ExpManager 挂在 Canvas 上ExpCanvas关 HUD 就退订，直接触发第 5 条
7升级判定用 if 不是 whileExpManager.GainExperience一次给大额经验会卡在「条满、等级不动」
8玩家死亡只 SetActive(false)PlayerHealth没有死亡 / 重生 / 重置流程
9没有存档全部等级、技能、背包、金币重开归零
